# Student Management System

## Final Python Project — Internship Task 3

A menu-driven Python application for managing student records.

### Features
- Add student
- View all students
- Search student by ID
- Update student
- Delete student
- Calculate total and average marks
- Grade calculation
- Class statistics
- JSON file storage
- Exception handling
- Object-Oriented Programming
- Inheritance
- Polymorphism
- Encapsulation
- Abstraction

## Requirements
- Python 3.9 or later
- No external packages required

## How to Run

Open the project folder in VS Code or Command Prompt.

```bash
python main.py
```

The program automatically creates `students.json` after the first student is added.
